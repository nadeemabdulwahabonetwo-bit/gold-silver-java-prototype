# Feedback and open decisions

## Agreed prototype inputs
Gold labels: 9, 18, 21, 24. Silver custom label: 28.
Prices: placeholders per gram. Random range: 1 inclusive to 25 exclusive.

## Feedback checklist
- [ ] Select price currency and provider.
- [ ] Define daily versus hourly observation times and stale-price handling.
- [ ] Define the relationship between market prices and scores.
- [ ] Specify whether random inputs remain simulation-only.
- [ ] Define how three gold grams and one silver gram affect valuation.
- [ ] Define what 100 design units represent.
- [ ] Define the ceiling threshold and its effect.
- [ ] Define issuance, ownership and redemption, if any.
- [ ] Select a license before public reuse.

Keep physical metal purity, custom allocation units, monetary value and combination scores distinct.
